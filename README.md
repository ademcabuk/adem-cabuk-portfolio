# Adem Çabuk - Kişisel Portfolyo

Bu proje, sade HTML, CSS ve JavaScript kullanılarak geliştirilmiş, tamamen duyarlı (responsive) profesyonel bir kişisel portfolyo web sitesidir. Geliştirme sürecinde hiçbir framework veya kütüphane kullanılmamış, modern web standartlarına uygun semantik bir yapı tercih edilmiştir.

## 🚀 Özellikler

- **Semantic HTML:** `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` gibi anlamlı etiketlerle oluşturulmuş temiz kod yapısı.
- **Tamamen Duyarlı (Responsive):** Mobil (375px), tablet (768px) ve masaüstü (1280px+) ekranlar için optimize edilmiştir.
- **JavaScript Etkileşimi:** Mobil cihazlar için açılır-kapanır hamburger menü ve sayfalar arası yumuşak kaydırma (smooth scroll) entegrasyonu.
- **Modern Tasarım:** CSS Flexbox ve Grid kullanılarak oluşturulmuş, kullanıcı dostu arayüz.
- **Hatasız Çalışma:** Konsol hatası (console error) veya bozuk/kırık bağlantı içermeyen temiz yapı.

## 🛠 Kullanılan Teknolojiler

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript
